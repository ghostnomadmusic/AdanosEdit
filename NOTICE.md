# Credits / Danksagungen

AdanosEdit is an unofficial fan tool for *Gothic 3*. It contains no game data;
it reads the files of an installed copy of the game at runtime.

Thanks to / Dank an:

- **g3dit** by georgeto (Apache License 2.0) – https://github.com/georgeto/g3dit  
  g3dit and its documentation served as the reference for several file
  formats. The navigation map handling (`g3/navmap.go`, adding zones to
  `NavigationMap.xnav`) is modelled on g3dit's implementation and was checked
  to produce byte-identical results.
- The makers of the **Gothic 3 Mod Starter** and of **G3IQ** (info and quest
  editor), whose tools and documentation describe the dialog and quest formats.
- The **Gothic 3 Community Patch** team.
- The Gothic community.
